# 草地生态学博士模拟器 · 求生指南 🌿🎓

一款**文字冒险游戏**：你扮演一名草地生态学博士生，从博一熬到毕业——或者，在某个意想不到的瞬间**嗝屁**。

> 死亡率不低，延毕率更高。祝你好运。

## 文件

| 文件 | 说明 |
|------|------|
| `index.html` | 游戏本体（样式、逻辑、绘图全部内嵌） |
| `bgm/delicate.m4a` | 敏感肌专属背景音乐（AAC 格式，兼容 Chrome） |
| `bgm/workhorse.m4a` | 牛马超人专属背景音乐 |
| `bgm/zen.m4a` | 佛系专属背景音乐 |
| `bgm/longao.m4a` | 龙傲天专属背景音乐 |
| `README.md` | 本说明文档 |

> 上传 GitHub 时，`index.html` 和整个 `bgm/` 文件夹**必须放在一起**（保持相对路径），否则音乐会 404。

## 玩法

1. 开局主菜单：**▶ 开始游戏 / ⚙ 设置 / 📖 玩法说明**。
2. 选择你的博士人设：
   - 🧴 **敏感肌**（脆皮大学生）：一言不合就嗝屁，做实验烫伤暴毙、被导师骂哭原地升天；但基础健康高、自愈强。
   - 🐴 **牛马超人**：工作能力拉满、科研进度 +50%，可惜身体被掏空，通宵过劳随时猝死。
   - 🧘 **佛系**：抗压拉满、情绪伤害减半，天塌下来也照样喝茶；就是没动力，进度稍慢。
3. 每个回合遇到一个事件，做出选择；七项属性实时联动：
   - **生命值**：归零 = 当场陨落。
   - **健康程度**：决定生命值的回复或流失。
   - **抗压能力**：减轻压力类事件的伤害。
   - **工作能力**：决定科研推进与答辩表现。
   - **人际关系**：影响工作与心情，关键时刻能救命。
   - **心情**：小幅度影响生命值，**大幅度影响工作能力**。
   - **科研进度**：决定你能否毕业、延毕多久。
4. 点右上角 **⚙ 设置**，可切换**浅色/深色主题**、调节**字体大小**、开关**背景音乐**，设置会自动保存。
5. 选人后自动播放对应人设的 BGM；游戏结束（任何结局）自动关闭 BGM。

## 龙傲天模式 🐉

**连续嗝屁或肄业 2 次**后，结局页会弹出「是否开启龙傲天模式」：

- 开启后：**除人际关系外所有属性几乎全满**，科研进度 ×3，情绪/生命伤害几乎免疫。
- 所有交互的**问题不变，但你的回答会全部换成装b台词**（每局每次随机抽不同台词，自称「我/本少/小爷」）。
- **博三即可提前毕业**：博三末触发专属剧情——被学界泰斗当众质疑 → 光速打脸 → 破格聘为教授 → 一年内评上院士 → 飞升，打脸所有看不起你的人。
- 龙傲天的 BGM 音量比其他人大一点。
